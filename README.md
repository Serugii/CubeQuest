# CubeQuest

**CubeQuest** – це інтерактивна платформа для навчання складання кубиків Рубика та інших головоломок. Вона пропонує користувачам різні челенджі, змагання на швидкість і покрокові відеоуроки для розвитку їхніх навичок у вирішенні головоломок.

## Опис проекту

CubeQuest надає користувачам можливість покроково вивчати складання головоломок, починаючи від класичного кубика Рубика 2x2 до більш складних головоломок, таких як Мегамінкс або 4x4. Сайт також включає функції для змагань і челенджів, де користувачі можуть випробувати свої навички на швидкість і змагатися за місце в глобальному рейтингу.

### Основні можливості:

- Покрокові відеоуроки з різних головоломок (2x2, 3x3, 4x4, Мегамінкс тощо)
- Система рівнів і звань для відстеження прогресу
- Челенджі та змагання на швидкість складання
- Глобальний рейтинг користувачів
- Інтерактивний профіль для збереження прогресу
- Система досягнень і нагород

## Структура проекту

- **frontend/** – Директория для файлів інтерфейсу користувача (React, Vue.js або інший фреймворк)
- **backend/** – Серверна частина (Node.js, Django, Flask або інший бекенд-фреймворк)
- **public/** – Статичні файли (зображення, стилі)
- **src/** – Основні файли додатку
- **database/** – Конфігурація та моделі бази даних
